========================================================================
      TruePeopleSearch · Windows 客户离线交付说明
========================================================================

本目录是受控的客户发布内容，不是 Git 工作副本。

客户版本不会：
  • 自动拉取 Git 或检查在线更新；
  • 自动启动 Docker、数据库迁移或后台作业；
  • 自动执行代理连通性测试；
  • 覆盖旧版本目录或导入已有运行数据。

交付与解压
  交付 ZIP、ZIP 的 SHA-256、外部解压器及其 SHA-256 四个文件。
  必须将哈希与可信发布记录中的期望值核对；随包的 .sha256 文件本身不证明发布者身份。
  如发布记录提供了 Authenticode 证书指纹，解压时传入该指纹以核对三份启动器的签名者。
  再通过外部解压器将 ZIP 解压到新的版本目录。
  包内 deploy\windows\README-RELEASE.md 是唯一的客户操作说明。

首次安装
  本包不携带 Python 依赖 wheelhouse、浏览器组件、容器镜像、数据库快照
  或任何客户配置。首次主机准备、依赖安装和数据库初始化必须由授权运维
  人员在独立流程中完成；不要运行旧的在线安装或在线检查脚本。

启动与验收
  在主机准备已通过后，使用 TruePeopleSearch.exe 或 start_client.bat。
  它们只启动受控 .env 所设端口的 127.0.0.1 本机控制台，并启用客户安全模式。
  启动器会验证该端口上的服务属于本次启动；端口占用或身份不匹配时不会打开浏览器。
  启动后请用 .env 中的 TPS_DASHBOARD_PORT 核验：
    http://127.0.0.1:<TPS_DASHBOARD_PORT>/api/health
    http://127.0.0.1:<TPS_DASHBOARD_PORT>/api/ready
    http://127.0.0.1:<TPS_DASHBOARD_PORT>/api/system/version

升级与回滚
  每次升级使用新目录，保留旧版本和经验证的数据快照。哈希/发布者校验、就绪检查或
  客户验收失败时，不切换版本，也不要通过 Git 或页面内更新功能重试。
